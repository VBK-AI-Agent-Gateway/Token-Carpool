# Security Policy

## Reporting a Vulnerability

We take the security of Token-Carpool seriously. If you discover a security vulnerability, please report it via:

- **Email**: support@agentgwapi.online
- **GitHub Security Advisory**: https://github.com/VBK-AI-Agent-Gateway/Token-Carpool/security/advisories/new

**Please do not** disclose security vulnerabilities in public issues.

## Supported Versions

We commit to acknowledging security reports within **72 hours** and providing a fix or mitigation within **7 days**.

## Best Practices

1. **Official sources only**: Download `.exe` files only from GitHub Releases.
2. **Verify integrity**: Check SHA-256 hash of downloaded files.
3. **Stay updated**: Regularly update to the latest version.
4. **Least privilege**: Run with normal user permissions, not administrator.

## Known Limitations

- This tool does **not encrypt** traffic between local and remote targets. Use HTTPS on the remote end for encrypted communication.
- This tool does **not validate** remote server certificates (handled by the underlying HTTP library).
